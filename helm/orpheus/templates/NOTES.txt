Access Orpheus at:
  {{ if .Values.ingress.tls.enabled }}https{{ else }}http{{ end }}://{{ .Values.global.domain }}

  <node-ip>  {{ .Values.global.domain }}

{{- else }}

No Ingress enabled. Access via port-forward:
  kubectl port-forward svc/{{ include "orpheus.client.fullname" . }} 8080:{{ .Values.client.port }}
  Then open: http://localhost:8080

{{- end }}

{{- if not .Values.server.persistence.enabled }}

⚠️  WARNING: Server persistence is DISABLED!
  Data is stored in an emptyDir volume and will be LOST when the pod restarts.
  Enable persistence for production use:
    helm upgrade {{ .Release.Name }} ./helm/orpheus --set server.persistence.enabled=true

{{- end }}

  1. Register this redirect URI in your Spotify Developer Dashboard:
     {{ include "orpheus.spotify.redirectUri" . }}

{{- if .Values.ollama.enabled }}

Ollama AI (model: {{ .Values.ollama.model }}):
  Pull the model after the pod is running:
    kubectl exec -it {{ include "orpheus.ollama.fullname" . }}-0 -- ollama pull {{ .Values.ollama.model }}

  Verify it's loaded:
    kubectl exec -it {{ include "orpheus.ollama.fullname" . }}-0 -- ollama list
