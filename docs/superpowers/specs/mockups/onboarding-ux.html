Design notes

  • When shown: After first successful Spotify auth, before engine starts. Skippable with "Use defaults" link at bottom.
  • Persistence: Saved to dj_preferences table. All editable later in Settings → DJ Personality section.
  • Defaults if skipped: Comfort Zone + Balanced chattiness + The Curator persona.
  • Custom persona: Free text stored as-is, injected into the LLM system prompt. Max 500 chars.
  • Theme: Follows existing dark theme with Lyre Gold accent. Matches the Orpheus visual language.
