Phase Breakdown — Build Sequence

Three shippable phases. Each adds value independently. Later phases build on earlier ones.

Phase 1 — LLM Curator + Onboarding (core)
What ships
Server: DJ Curator
  • ListenerContext assembler
  • Pool builder (library-only for now)
  • LLM call with JSON schema constraint
  • Pool validation + backfill
  • Transition validation safety net
  • Rapid-skip handling + bridge tracks
Server: Engine Integration
  • Proactive scheduling (30s buffer)
  • 3-track batch queue loading
  • Fallback to algorithmic selector
  • Auto-retry every 2 min
  • New WS events (curator_update, fallback, restored)
Server: AI Module
  • Schema-constrained Ollama generation
  • 4 persona system prompts
  • Chattiness prompt hints
  • DJ preferences API endpoints
  • Onboarding status endpoint
Server: Database
  • Migration v6: dj_preferences table
  • DJ preferences repository
  • Persona, chattiness, discovery appetite
  • Custom persona text storage
  • Onboarding completed flag
Client: Home Screen
  • DJ patter banner
  • Pick reason below track info
  • Up Next queue (3 tracks)
  • Persona chip in status bar
  • Auto-pilot fallback indicator
Client: Onboarding + Settings
  • 3-step onboarding wizard
  • DJ Personality settings section
  • DJ Voice section (greyed, Phase 3)
  • Onboarding provider + API calls
Depends on
Nothing — builds on existing infra
