New UI elements summary

Home Screen
  • DJ patter banner — above album art, shows LLM commentary
  • Pick reason — below track info, why the DJ chose this track
  • Up Next queue — shows next 2 tracks with source tag (library/similar/discovery)
  • Persona chip — status bar shows active persona
  • Fallback indicator — "Auto-pilot" badge when LLM is offline
Settings Screen
  • DJ Personality section — persona picker, chattiness toggle, discovery appetite
  • DJ Voice section (Phase 3) — engine, voice, volume — greyed out until TTS is implemented
  • Ratio visualization — mini bar + percentages update with appetite selection

New WebSocket events

curator_update — { picks: [...], patter: "...", source: "llm" } → update patter banner + queue
curator_fallback — { reason: "timeout" | "unavailable" } → show auto-pilot indicator
curator_restored — {} → hide auto-pilot, resume DJ mode
state_updated — (existing) extended with curator metadata
track_changed — (existing) extended with pick reason
