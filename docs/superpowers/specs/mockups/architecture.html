Key changes from today

  • DJ Curator replaces the Selector as the primary brain — LLM picks 3 tracks + patter
  • Pool Builder extends Candidate Pool with multi-source support + user-tunable ratios
  • Intelligence Pipeline demoted to fallback role + transition validation
  • Playback Engine gains proactive scheduling (call LLM ~30s before queue runs out)
  • AI Module gains schema-constrained generation + persona prompt management
  • External Sources and TTS are designed now but built in Phase 2 and 3
